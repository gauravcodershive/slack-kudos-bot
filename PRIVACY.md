# Privacy Policy — Kudos Slack App

Last updated: July 2026

## What data we access

Kudos requests only two permissions from Slack:
- **commands** — to receive the `/kudos` slash command you type.
- **chat:write** — to post the resulting kudos message to the channel.

## What we store

Kudos does **not** store, log, or retain any message content, user names, or channel names beyond the moment needed to process a single `/kudos` command and post the resulting message. No database of user activity is kept.

The only information retained is a workspace's authentication token, which is required to allow the app to post messages on that workspace's behalf. This token is not shared with any third party.

## Third parties

Kudos does not share any data with third parties. All processing happens directly between Slack and the app's own server.
